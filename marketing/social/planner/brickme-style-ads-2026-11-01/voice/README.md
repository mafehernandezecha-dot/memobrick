# Voice-over (computer voice, free, offline)
Piper TTS (open source) with the LibriTTS "high" US English multi-speaker model, run locally; no paid app.
Voices: speakers 881, 886, 564, chosen from 60 random voices as the female voices with the most natural pitch movement (least flat).
Script: narrator voice, never as a customer. Built phrase by phrase, so vo_cues.json gives the exact start/end of each phrase and its matching caption.
