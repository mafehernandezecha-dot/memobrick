# Kit offers: rules

Written 2026-10-28 by outreach-gift-guide-pr. This file restates rules the owner already set. It adds no new permission.

- **Default is commission only** (owner, 2026-10-14): an invite to the Memobrick creator program on Shopify Collabs, 10% commission on every sale and the creator's own 10% off code (the only tier, never more). Apply at https://mymemobrick.com/pages/collabs.
- **Sample kits for press: case by case, strong outlets only, each kit offer needs the owner's approval in the queue** (Facts table, `marketing/shared/offers-calendar.md`, 2026-10-11).
- **A kit needs evidence of real reach and clear fit** (a published gift guide with real traffic, an editor or creator who reviews physical products, or strong real engagement with the audience), making sales well above the kit's cost plausible, or audience-fit score 5, or 4 with evidence of reach. Record the evidence in the targets file and in the kit file.
- **One `offer` item per kit**, with its own file here (`<slug>-kit.md`), separate from the pitch's `send` item. Approving a pitch never approves a kit. The Gmail draft or form text for a kit pitch is made only when both items are approved.
- **Nothing is owed in return** for a kit: no required post, no guaranteed coverage, and we never pay or offer payment.
- A kit ships only after the person replies, says yes, and sends a photo and a shipping address. The owner ships it by hand.
- A withdrawn or archived kit offer is never acted on (for example green-wedding-shoes-kit.md, withdrawn 2026-10-14).
