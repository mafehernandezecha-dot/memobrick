# Calm Build Gift (concept, 2026-10-28)

Asked by Eden: "make one gift for people with autism". Uses only what Memobrick already sells and ships, so nothing changes in production or fulfillment.

## The gift

- **The kit:** the 16×16 kit ($69.88 on 2026-10-12, re-check before quoting): the smallest size, one baseplate, 2,500 bricks, about 2.5 hours, which can be split into short sessions. The bricks already come in labeled bags sorted by color, matching the color map, which suits one-bag-at-a-time building.
- **The photo:** their own choice of what matters to them, such as a pet, family or a special interest (only their own photos; no trademarked characters in our images or ads).
- **The free printable "Calm Build Plan":** `calm-build-plan.pdf`, made by `make_pdf.py`. It has 3 pages:
  - a 6-step plan (quiet spot, session length, one color bag at a time, one row at a time, stopping, looking back)
  - a 50-row tracker for the 16×16
  - cut-out NOW / NEXT / STOP HERE / BREAK / DONE TODAY / FINISHED! cards
  It is a free download from the gift page and the blog hub, not a new item in the box.
- **Optional:** the 16×16 frame ($49).

## Wording rules

The rules from `marketing/seo/briefs/2026-10-28-autism-calm-building-research.md` apply.
- Call it calm, predictable, built one row at a time, something to build together or alone.
- Never say it helps, improves or treats autism, and never call it therapy.
- Small-parts note on every page.
